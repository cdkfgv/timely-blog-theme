落地方式（确认后才动代码）
  • 24 个图标集中定义成一个 <svg><symbol> 精灵块（隐藏在 body 末尾），使用处写 <svg class="i i-16"><use href="#i-search"/></svg> —— 图标只存一份定义。
  • 尺寸用 3 个 class 覆盖（14 / 16 / 20px），颜色继承 currentColor，明暗自动跟随，不需要两套图。
  • 同时删掉 FontAwesome 的 all.min.css 引用：页面少 1 个 CSS + 最多 3 个 woff2 字体请求（约 375KB，且首访会有图标闪白）。
  • 形状可调：stroke-width 统一在 1.9~2.1 之间，如果你觉得太细，我可以整体调粗一档再给你看。
风格差异（重点看这个）
  • FontAwesome 是实心填充，描边 SVG 视觉更轻。14px 小尺寸下描边细节会略弱于实心 —— 主要影响 fa-tags（双层标签）、fa-chevron-*（细箭头）。
  • 如果你更想保留现在的「实心」观感，我可以改用 Heroicons Solid 出一版对比稿，你再挑。
  • 验收方式：确认后我直接改 EJS 主题，你在本地分享站上逐页点一遍对照。
