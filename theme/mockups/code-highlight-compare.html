④ 建议

动作说明
① 必做：语言名映射 text-x-sh → bash；text-x-yaml → yaml；text-x-trilium-auto → 自动探测或 plaintext； application-typescript → typescript；application-javascript-env-backend → javascript。 规则：剥掉 language- 前缀后，把 text-x- 换成空、application-*-env-backend 归一到 javascript。 这层不做，换任何库都没高亮。
② 换 hljs 的理由 bash / yaml / docker 这类「配置与脚本」是它的强项；单文件接入，不用维护一堆 components/*.js； github-dark 配色和主题现在的 zinc 暗色调更搭（对比第一栏：tomorrow 的紫红在长代码里更累眼）。
③ 不建议 Shiki 要 wasm（≈700KB）或服务端预渲染。Trilium 分享模板里塞 wasm 不划算也不稳；「配色和 VS Code 一模一样」对博客场景收益过重。
④ 最低成本方案 只想让现在的 Prism 生效：补 prism-bash / prism-yaml / prism-docker 三个包 + 上面那层语言名映射。 完全可行，就是配色沿用 tomorrow。
